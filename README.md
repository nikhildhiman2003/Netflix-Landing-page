Netflix Landing Page (React.js)

Project Overview
This project is a **Netflix Landing Page clone** built using **React.js**. It replicates the look and feel of Netflix’s homepage, including a responsive UI, movie rows, banners, and smooth scrolling functionality.

The goal of this project is to practice **React fundamentals**, **component-based architecture**, and **modern UI design using Tailwind CSS**.

Features

 Modern Netflix-style UI,
 Movie/TV show cards display,
 Horizontal scrolling rows (like Netflix),
 Banner section for featured content,
 Fully responsive design,
 Fast rendering using React components,
 Clean and reusable code structure.


## 🛠️ Tech Stack

 **Frontend:** React.js
 **Styling:**  Tailwind CSS
 **Icons:** React Icons 
 **State Management:** useState, useEffect
 **Hooks Used:** useRef (for scrolling)
